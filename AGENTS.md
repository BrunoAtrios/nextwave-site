# Site Next - Institucional

Este projeto faz parte do ecossistema **00_SISTEMA_BRUNO**.

## Comando Universal
Diga "atualize o contexto com tudo que fizemos" ou "atualiza o cérebro" e a IA executa:
- Leia o `contexto_ia.md` gerado deste projeto.
- Rode Graphify somente quando a sessão alterou a estrutura relevante de código.
- Crie lote JSON temporário com fatos, decisões, mudanças e tarefas relevantes, sem segredos.
- Execute `context save --project site-next --file <lote-temporario.json>`.
- Nunca edite `contexto_ia.md` diretamente.

## Graphify
`/graphify .` — mapeia o código em grafo de conhecimento

## Cérebro Central
`..\_CEREBRO\` — notas do Obsidian com visão geral

## Fonte da Verdade
`C:\Users\Dev\.context-lite\context.db` é a fonte estruturada. `contexto_ia.md` é a visão gerada e versionada.
